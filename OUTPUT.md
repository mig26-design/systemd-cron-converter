# `output/` static site

Generated by:

```bash
python3 build_utilities.py
```

No pip packages. Re-running the script deletes and recreates `output/`.

Serve it:

```bash
python3 -m http.server 8080 --directory output
```

## Layout

| Path | URL (`https://cron2systemd.dev`) |
| --- | --- |
| `output/index.html` | `/` (hub listing all tools) |
| `output/{slug}/index.html` | `/{slug}` (20 utilities) |
| `output/oncalendar-cron-converter/index.html` | `/oncalendar-cron-converter` (copied flagship converter) |
| `output/sitemap.xml` | `/sitemap.xml` |
| `output/robots.txt` | `/robots.txt` (`Sitemap: https://cron2systemd.dev/sitemap.xml`) |
| `output/assets/` | shared CSS/JS, favicon, `converter.js` |

Canonical links and Open Graph `og:url` omit a trailing slash: `https://cron2systemd.dev/{slug}`.

## Deploy

Point Cloudflare Pages (or any static host) at `output/`:

- Build command: `python3 build_utilities.py` (or generate locally and skip the build)
- Output directory: `output`

The repository root remains the original converter so an existing Pages project with output directory `.` keeps working until you switch it.
